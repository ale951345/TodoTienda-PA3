# Registro de cambios - TodoTienda PA3

## Versión 1.0.0 - PA2
- Desarrollo de la aplicación web TodoTienda.
- Implementación del CRUD de productos.
- Conexión con MongoDB mediante Mongoose.
- Desarrollo del backend con Node.js y Express.
- Creación de la interfaz principal en Angular.

## Versión 2.0.0 - PA3
- Implementación del registro e inicio de sesión.
- Protección de contraseñas mediante bcrypt.
- Incorporación de autenticación con JWT.
- Implementación de roles de administrador y usuario.
- Protección de rutas y operaciones del backend.
- Integración de Axios en React.
- Desarrollo de un panel secundario con React y TypeScript.
- Implementación de Context API para gestionar la sesión.
- Incorporación de rutas protegidas y cierre de sesión.
- Conexión de Angular y React al mismo backend.
- Mantenimiento de las operaciones CRUD sobre MongoDB.
